Install steps

Pick your phone. The steps are the same for both apps — just open the app first, then follow along.

Android · Chrome

  1. Open the app: tap “Open Trix” or “Open Tiki Talker” above.
  2. Wait for the page to load. A small “Install” button appears in the top-right of the app.
  3. Tap Install → then tap Install again in the pop-up.
  4. Done — the app icon appears on your home screen. Open it like any app.

No Install button? Tap the ⋮ menu (top-right of Chrome) → Add to Home screen → Install.

iPhone · Safari

  1. Open in Safari (not Chrome) and go to the app page.
  2. Tap the Share button — the square with an arrow ⬆ at the bottom.
  3. Scroll down and tap Add to Home Screen.
  4. Tap Add (top-right). The icon lands on your home screen.

No “Add to Home Screen”? Make sure you're in Safari — Chrome on iPhone can't install apps. Scroll the share sheet fully; the option is near the bottom.

🛠 If the “Install” option never appears

  • Use the right browser: Android → Chrome; iPhone → Safari. Other browsers often hide the option.
  • Use the real link, not a preview: open the app from this page's buttons, not from a chat preview.
  • Needs HTTPS: install only works on a secure https:// address (or localhost). If you're on a plain http:// link, the browser blocks it.
  • Already installed? If the icon is already on your home screen, the Install button hides itself — that's normal.
  • Still stuck? Use the manual route: Chrome ⋮ → Add to Home screen; Safari Share → Add to Home Screen.
